# Renditions

The Rendition Factory is a service responsible for generating various renditions (alternative formats or versions) of media assets stored in Databox. It utilizes a set of transformers to process and convert the original media files into different renditions based on predefined configurations.

## Supported input formats

The default preview rule first runs `extract_embedded_preview`, which uses ExifTool (shipped through the `exiftool/exiftool` composer package) to pull the embedded preview out of Illustrator (AI), EPS, InDesign (INDD) and camera raw files; the extracted image, or the original file when none is found, then goes through ImageMagick via the `imagick` extension. ImageMagick relies on tools installed in the worker image: Ghostscript for PDF, PostScript, EPS and AI files, and the librsvg coder (`imagemagick-svg`) for SVG. Videos and audio go through FFmpeg and office documents through LibreOffice.
